## Open research judgements

- What qualifies as an event shift here: action goal, information change, character configuration, location or a combination? Existing labels support exploratory comparison but not a universally defined event ontology.
- When do observed changes constitute organisation or a device with a function, rather than incidental image difference? This requires film analysis alongside measurement.
- How should fade–black–new-image compounds and file-edge/credit material be counted? A detector cannot settle the analytical unit.
- Which editions, genres and institution lineages are comparable? Exact names should not be automatically merged, and metadata-only “single studio” does not prove exclusive collaboration.
- Which negative cases constrain the theory? E010, E006 and the stronger duration baseline belong in the argument, not only in an appendix.

The best next independent experiment is a frozen event-correspondence comparison on new reference material, with framing/setting conditions and ordinary-cut controls. It remains proposed work. The present preparation should stop when the existing bounded result is clearly evidenced and interpretable; neither a large refactor nor an expanding model list makes that argument stronger by itself.
